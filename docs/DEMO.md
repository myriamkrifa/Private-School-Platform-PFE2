# Demo Scenario

This walkthrough shows the platform end-to-end using the seeded demo data.
Make sure both servers are running:

```
# Terminal 1
cd backend
npm run dev          # http://localhost:5000

# Terminal 2
cd frontend
npm run dev          # http://localhost:5173
```

All seeded passwords are `password123`.

---

## 1. Admin walkthrough

1. Open http://localhost:5173/login.
2. Sign in as `admin@school.com` / `password123`.
3. **Dashboard** — review:
   - Stat cards: Students, Teachers, Parents, Classes, Subjects, today's
     absences/lates, active academic year.
   - Recent announcements + recent activity (audit log).
   - Latest grades.
4. **Academic Years** (left sidebar): the year `2026-2027` is already active.
   Optionally create another year and toggle the `Active year` checkbox.
5. **Classes**: open a class (e.g. `Secondary 1`) and review the students,
   teachers, and teaching assignments. Try removing/adding a student and a
   teacher.
6. **Subjects** (admin-only management): edit `Mathematics`, change its
   coefficient to 4, save. Create a new subject (e.g. `Physics` / `PHY` / coef.
   3 / Secondary).
7. **Teaching Assignments**: pick a teacher + class + subject and click
   `Assign`. Remove an assignment with the `Remove` button.
8. **Reports**:
   - Generate a class report for `Secondary 1` and inspect the per-subject
     averages and attendance summary.
   - Click `Export CSV` to download the class report.
   - Generate a student report for `Mariem`.
   - Inspect the teacher workload table.
9. **Announcements**: publish a new announcement targeted to `PARENT`. Verify
   that you can also target a specific class.
10. **Users**: open the `Create User` modal and provision a new
    student + parent (auto-credentials shown only once).
11. Logout.

## 2. Teacher walkthrough

1. Sign in as `teacher.math@school.com` / `password123`.
2. **Dashboard** — review assigned classes / subjects / today's attendance /
   recent grades / recent assignments / parent messages.
3. **Grades**: select a class (e.g. `Secondary 1`), a subject (e.g.
   `Mathematics`), enter an evaluation title, type `EXAM`, today's date.
   Enter scores for each student (0–20) and click `Save Grades`.
4. **Attendance**: select the same class + subject + today's date, set a
   couple of statuses to `ABSENT` / `LATE`, click `Save Attendance`. Parents
   are notified automatically.
5. **Assignments**: select class `Secondary 1` + subject `Mathematics`, fill
   in title `Practice worksheet`, set due date, target `FULL_CLASS`, click
   `Create`.
6. **Courses & Materials**: pick class + subject, add a material (text content
   or external URL).
7. **Messages**: open `Messages`, select a parent (e.g. `Mr. Ali Ben Salah`),
   compose a short message and send. The parent will receive it in their
   inbox + a notification.
8. Logout.

## 3. Parent walkthrough

1. Sign in as `parent.ali@school.com` / `password123`.
2. **Dashboard**:
   - See the children list, latest grades, recent absences/lates,
     announcements (everyone or PARENT targeted), and unread notifications.
   - Click `View grades` on a child to navigate to grades.
3. **Grades**: pick a child from the dropdown to see history and overall /
   weighted averages. Click `Export CSV`.
4. **Attendance**: pick a child to see the attendance log. If you see an
   absence record ID, you can submit a justification from the `Justify
   Absence` form (status becomes `EXCUSED`).
5. **Announcements**: read announcements relevant to parents.
6. **Messages**: write to the math teacher and click `Send`.
7. **Notifications**: see notifications generated by the teacher's previous
   actions (new grade, new attendance, new message).
8. Logout.

## 4. Student walkthrough

1. Sign in as `student.mariem@school.com` / `password123`.
2. **Dashboard**:
   - Class card with name + room + level.
   - Stat cards: recent grades, days present / absent / late, upcoming
     assignments.
   - Sections: latest grades, upcoming assignments, recent attendance, my
     subjects (with teacher names), announcements.
3. **Subjects**: read-only list of subjects assigned to your class.
4. **Grades**: read-only list of personal grades.
5. **Attendance**: personal attendance history.
6. **Assignments**: see assignments targeted to your class. Optionally use the
   `Submit assignment` form to upload a submission (text + URL).
7. **Courses**: browse course materials shared by teachers.
8. **Announcements**: read announcements (general or class-targeted).
9. Logout.

## What to highlight in the live demo

- **Role-aware navigation**: switching role completely changes the sidebar.
- **Authorization is enforced server-side**: try as a parent to load
  `GET /api/students/<other-student-id>` — you'll receive a `403 Forbidden`.
- **Audit log**: every grade, attendance, class, announcement, and teaching
  assignment action is captured for the admin (visible on the dashboard).
- **Notifications**: marking attendance immediately creates `ABSENCE` /
  `LATE` notifications for the linked parents, and grades create `GRADE`
  notifications.
